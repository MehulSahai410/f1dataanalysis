# PROJECT OVERVIEW: F1 GRID VS FINISH ANALYSIS

 1. Objective
 Quantify how much qualifying position determines race outcome vs race-day factors.

 2. Key Findings
- Pearson (0.564) & Spearman (0.537) confirm a moderate correlation.
- Starting grid explains only ~31.8% of finish variance (R² ≈ 0.32).
- Pole conversion rate is 43.16% (505 wins from 1,170 pole starts).

3. Data Insights
- Asymmetry: Backmarkers rarely reach podiums, but front-runners often drop due to DNFs.
- High midfield shuffling (P8-P18) lowers Spearman relative to Pearson.

4. Strategy Analysis
- Evaluates driver recovery efficiency when starting P11 or lower (min. 25 starts).
